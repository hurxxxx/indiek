# 가사 주제로 음악을 발견하는 콘텐츠

한국어를 잘 모르는 청취자가 곡의 이야기를 이해하고, 같은 주제를 다룬 다른 음악을 찾을 수 있도록 한다. Reddit 독자가 요청한 아티스트 추천, 영어 가사 해설, 주제별 탐색 중 앞의 두 항목을 공원과 예빛의 아티스트 페이지에서 먼저 다룬다. 주제별 탐색 화면은 후속 작업이다. 한 댓글은 구체적인 독자 의견이며 전체 이용자의 수요를 입증하는 자료로 취급하지 않는다.

## 첫 두 곡

| --- | --- | --- | --- |
| gongwon 공원 — Flower 곰팡이 | [공식 음원](https://www.youtube.com/watch?v=BvvMdJ6-EIM) | 꽃과 곰팡이의 대비, 어려운 감정 속에서도 자라고 사랑받고 싶은 마음 | Self-acceptance, Self-worth |
| Yebit 예빛 — Only You 불안한 내 맘 달랠 곳은 너밖에 없어 | [공식 라이브](https://www.youtube.com/watch?v=Lceij_QGihY) | 그대로인 장소와 달라진 관계, 겉으로 괜찮은 척하는 마음 | Longing, Changing relationships |

곡 소개, 짧은 구절의 영어 번역, 표현의 뉘앙스, 전체 의미에 대한 독립적인 해설과 원문 출처를 제공한다. 전문 가사나 행별 전체 번역을 제공하는 형식은 아니다. 가사 속 화자의 상황을 가수의 사생활이나 실제 경험으로 단정하지 않는다.

공원의 [EP 0 전체 라이브](https://www.youtube.com/watch?v=DFFuWt1Ea6o)는 아티스트 페이지의 별도 감상 항목이다. 영상에 적힌 다섯 곡의 시작 시각을 표시하며, 곰팡이는 18:55에 시작한다. 앨범은 여섯 트랙이며 이 라이브는 다섯 곡이므로 앨범 전곡이라고 표기하지 않는다. 표의 시각은 안내용이며 현재 사이트 내부의 구간 재생 버튼은 아니다.

## 다음 작업

1. **기존 곡의 해설을 확장한다.** 선우정아 Run with Me, 최유리 Forest, 한로로 Even if you leave 등은 조사 후보이다. 기존 소개에 근거가 있더라도 원문과 작사자를 다시 확인하고, 글을 읽기 전후 무엇을 새롭게 이해하게 되는지 정한다. 해설이 없는 곡에 주제를 자동 추측해 붙이지 않는다.
2. **같은 주제의 가이드 한 편을 만든다.** 검토된 3~5곡이 모이면 각 곡이 그 주제를 어떻게 다르게 다루는지 선정 이유를 쓴다. 음악의 분위기와 가사의 주제를 구분한다. 두 곡만으로 기존 큐레이션의 3~5곡 기준을 바꾸지 않는다.
3. **Guides에 By lyrical theme 진입점을 만든다.** 여러 주제 선택, 결과 없음, 초기화, 상세 페이지 왕복 시 조건 유지, 직접 재생·저장을 설계한다. 한 곡은 여러 주제에 포함할 수 있다. 곡 수와 아티스트 수를 혼동하지 않는다.
4. **주제 목록과 연결을 정비한다.** 현재의 문자열 주제를 안정적인 ID와 표시 이름으로 정리할지는 탐색 화면을 만들 때 결정한다. 곡·가이드·Stories에서 해설을 재사용하거나 연결하고, 같은 글을 별개 기사처럼 중복 발행하지 않는다.
5. **독자 반응으로 보완한다.** 기존 동의 기반의 실제 재생·저장·공유 지표와 구체적인 댓글을 함께 본다. 조회수만으로 가사 해설의 효과를 단정하지 않으며 측정 확장이 필요하면 별도로 설계한다.

주제별 페이지의 완료 기준은 근거가 있는 분류, 영어로 이해 가능한 선정 이유, 기존 곡 누락 방지, 검색·Saved·공통 플레이어와의 연결이다. 독립 상단 탭과 발행 주기는 콘텐츠가 쌓인 뒤 결정하며 이번 작업으로 자동 발행 일정을 변경하지 않는다.

## 관리 위치와 공개 준비

- 콘텐츠와 기본 영상은 `content/catalogue.json`의 곡 항목에 둔다. `lyricNotes`는 해설·주제·짧은 인용과 번역·가사 출처, `performances`는 별도 전체 공연을 관리한다.
- 첫 두 곡의 근거와 검수는 [조사 기록](../editorial/research/gongwon-yebit.json)에 둔다. 원문이나 해설 변경 시 해당 내용의 사실·문장 검수를 다시 한다.
- 아티스트 소개는 `/artists/gongwon/`, `/artists/yebit/`이며 홈·Artists·Listening Room·기존 가이드·입문 가이드 후속 목록·검색·홍보용 카탈로그에 포함한다. 전체 공연은 곡 목록의 수량에 더하지 않는다.
- 공원·예빛의 최초 공개일은 이번 배포일인 2026-10-21로 기록해 RSS·최근 추가에 반영한다. 이후 수정 때 최초 공개일은 바꾸지 않는다.
- 가사 해설·라이브 등 주요 추가 내용은 홈의 New on indiek에서도 알린다. 공원·예빛의 소개 문안은 `content/updates.json`에 2026-10-21 공개 항목으로 등록되어 있으며, 이후 운영은 [Home updates](../README.md#home-updates)를 따른다.
- 새 발매 표지의 출처와 확인되지 않은 이용 허가는 `content/image-rights.json`에 기록한다. 출처 표기는 이용 허가 확인을 뜻하지 않는다.
- 빌드·검증 명령은 [README](../README.md), 배포와 자동 게시 서버 카탈로그 갱신은 [배포 문서](../deploy/README.md)에 따른다. 로컬 생성은 원격 배포나 서버 갱신을 의미하지 않는다.

## 확인 상태

2026년 10월 21일 공원의 대표곡을 곰팡이(Flower)로 맞추고 소개·영어 해설·홈 소식을 갱신했다. `npm run build:preview`와 `npm run check`에서 119개 테스트 및 28개 정적 페이지 검사가 통과했다. 새 공식 음원의 실제 임베드 재생, 데스크톱·모바일 390×844 해설 배치, 곰팡이 한글 검색, Saved 직접 재생과 삭제를 확인했다. 테스트용 저장 변경은 원래 목록으로 복원했다. 아티스트·저장 ID는 유지하며 전체 라이브는 별도 항목으로 남긴다.

전체 라이브와 예빛 영상, 가로 모바일 배치와 Saved 0·1·13곡 등 초기 검증 결과는 [조사 기록](../editorial/research/gongwon-yebit.json)의 `initialVerification`에, 곰팡이 교체 검증은 `verification`에 구분한다.

Saved 50곡 화면과 실기기 키보드는 수동 검증하지 않았다. 오류·자동 재생 차단·순차 재생 끝 처리는 자동 테스트 범위이며 실제 환경의 모든 상태를 재현하지 않았다. 전체 화면 버튼은 표시되지만 브라우저 미리보기에서 실행 후 전체 화면 전환이 확인되지 않아 진입·복귀는 미확인으로 남긴다.

주제별 탐색 탭과 3~5곡 주제 가이드는 후속 작업이다. 원격 배포·자동 게시 서버의 카탈로그 갱신 결과는 배포 문서에서 관리한다.
