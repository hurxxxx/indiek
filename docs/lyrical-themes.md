# 가사 해설

가사 콘텐츠는 영어 해설을 기본으로 유지한다. 가사가 전하는 의미와 감정의 흐름을 구체적인 장면·표현에 기대어 부드럽고 과장 없이 풀어 준다. 작성·검수 기준은 [가사 해설 지침](../skills/indiek-editorial/references/editing.md#lyric-commentary)에 둔다. 현재 16곡 해설은 이 방향으로 유지하며, 번역은 별도 요청이 있을 때 다룬다.

## 현재 범위

`content/catalogue.json`의 소개 곡 16곡 모두에 영어 `Inside the lyrics` 해설이 있다. Editor’s pick인 윤미래의 Breath도 포함한다. 공원·예빛의 기존 해설은 인용·번역 박스를 없애고 표현의 뉘앙스를 본문에 담았다. 현재 해설에는 가사 전문이나 행별 번역이 없다.

각 아티스트 페이지에는 곡별 해설과 가사 출처가 표시된다. 가이드의 선정곡·입문 가이드 후속 목록에서 해당 해설로 바로 이동할 수 있다. 홈의 아티스트 소개도 해설을 연결하며, 기존 기사·추가 곡 링크와 함께 최대 세 개의 연결을 표시한다.

외부 추천 링크인 `moreTracks`와 공원 전체 라이브의 챕터는 독립적인 곡 소개에 포함하지 않는다. 이후 정식 소개 곡으로 추가할 때 가사 출처를 확인하고 해설을 함께 검토한다. 전체 라이브는 기존의 별도 재생 항목으로 유지한다.

## 근거와 검수

- 현재 16곡의 원문 출처·작사 크레딧·해설의 초점·정확한 원고에 대한 사실 및 문장 검수는 [조사 기록](../editorial/research/catalogue-lyric-notes.json)에 둔다. 가사 원문은 저장하지 않는다.
- [공원·예빛의 이전 조사 기록](../editorial/research/gongwon-yebit.json)은 최초 소개와 영상 교체의 근거를 보존한다. 현재 해설의 검수는 위의 전체 곡 기록을 따른다.
- 해설의 근거가 되는 가사와 곡·작사 크레딧을 확인한다. 창작자가 밝힌 배경은 출처와 함께 구분하며, 편집 해석이 가사에서 확인할 수 있는 범위를 넘지 않는지 검토한다.
- 콘텐츠 구조와 실행·검증 방법은 [README](../README.md#artists-and-tracks)를 따른다. 원고를 바꾸면 해당 검수를 다시 한다.

## 공개 상태

전체 곡 해설 확장의 홈 소식은 `content/updates.json`에서 공개일과 함께 관리한다. 아티스트 페이지의 최초 공개일은 유지하고 실제 수정일만 반영한다. 공개 절차는 [Home updates](../README.md#home-updates)를 따르며, 배포 결과는 [배포 문서](../deploy/README.md#확인과-복구)에 기록한다. RSS는 기존 공개일이 있는 페이지를 제공하며, 이 변경으로 미확인 공개 날짜를 만들지 않는다.

주제별 검색 화면이나 새 가이드는 이번 범위에 포함하지 않는다. 향후 필요할 때 검토된 해설을 바탕으로 별도 설계하며, 분류만으로 비슷한 곡이라고 단정하지 않는다. 배포와 자동 게시 서버의 운영 기록은 [배포 문서](../deploy/README.md)에서 관리한다.
