# 성장 3단계 계획 (2027-11 ~ 2029-04)

목표: 2029년 4월까지 월 100만 방문. 비교 대상은 영어권 K-pop 가사 사이트 규모(월 약 100만, 외부 추정)다. 한국 인디만으로는 이 규모의 사례가 없으므로 다음을 함께 한다.

- 범위를 한국 음악 전반의 큐레이션으로 넓힌다.
- 영어 외 언어판을 연다.
- 검색에만 의존하지 않도록 참여·커뮤니티·뉴스레터 유입을 키운다.

[1단계](growth-phase-1.md)·[2단계](growth-phase-2.md)의 원칙과 측정 방식을 잇는다.

## 시작 조건

- 2단계 평가에서 월 방문 7만 이상, 월 성장률 15% 이상
- 콘텐츠 유형별 생산 비용과 페이지당 방문 데이터
- 가사 라이선스 시범(E1)과 수익화(E5)의 결과
- 3단계 인력과 예산의 확보 여부. 확보하지 못하면 목표 시점을 늦추고 상위 유형에만 집중한다.

## 작업 흐름

### P3-W1. 콘텐츠 규모와 뉴스 데스크

- 아티스트 1,000명 → 3,000명, 곡 4,000곡 → 15,000곡, 앨범 페이지를 함께 늘린다.
- 매일 발매·공연·OST 소식을 확인된 사실만으로 낸다. 출처와 확인 시각을 표시한다.
- **연말 "indiek Listeners' Awards":** 2027년·2028년 12월에 연다. 투표, 결과 발표, 수상 아티스트 인터뷰로 이어지는 연례 행사로 만든다.

### P3-W2. 가사 (F2 승인 시)

- 라이선스 API의 표시·캐시·출처 표기 조건을 빌드와 API에 반영한다. 조건을 벗어나는 저장이나 재가공은 하지 않는다.
- 곡 페이지는 해설, 가사, 공식 번역(있는 경우), 공식 녹음 순서로 보여 준다. 기존 해설 원칙은 유지한다.

### P3-W3. 언어판

- 언어별 첫 3개월: 입문 가이드, 상위 300개 아티스트·곡 페이지, OST 허브, 페스티벌 가이드부터 번역한다.
- 언어별 SNS 계정은 해당 언어 유입이 월 2만을 넘을 때 연다.
- 언어판마다 Search Console 성과를 따로 보고, 성과가 낮은 언어는 확장을 멈춘다.

### P3-W4. 계정·커뮤니티 (F4)

- 계정 없이도 모든 감상과 Saved는 지금처럼 쓸 수 있다. 계정은 공개 목록, 팔로우, 알림, 댓글에만 필요하다.
- 댓글은 곡 페이지에만 연다. 신고, 자동 필터, 운영자 검토를 갖춘 뒤 공개한다. 1차 검토와 답글은 AI 운영 에이전트가 하고, 사람은 보류된 항목만 판단한다.
- AI 운영 에이전트가 각 언어판 SNS·커뮤니티에도 응대한다. 언어별 검수자가 표본을 확인한다.
- 발매 알림(이메일): 팔로우한 아티스트의 신곡·공연을 알려 재방문을 만든다.
- Discord 등 외부 커뮤니티를 공식 공간으로 운영하고 사이트 콘텐츠와 연결한다.

### P3-W5. 데이터와 차트 (F6)

- 주간 리스너 차트, 연말 어워즈, 장르·지역별 청취 경향을 공개 데이터로 낸다.
- 차트 인용과 보도는 링크와 신뢰를 함께 만든다. 집계 방식과 조작 방지 방법을 공개 페이지에 둔다.

### P3-W6. 영상·파트너십

- YouTube 정규 시리즈(주 2편)와 Shorts를 레이블 허락 범위에서 운영한다.
- 해외 한국문화원, 관광기관, 페스티벌과 공연·입문 가이드 공동 게재를 추진한다.
- 스트리밍 플랫폼의 한국 음악 기획과 협업을 제안한다.

### P3-W7. 기술

- **PostgreSQL 이전:** 계정을 열 때 옮긴다. 이전 리허설과 롤백 절차를 먼저 만든다.
- **API 확장:** 서버를 2대 이상으로 늘린다. 정적 파일은 CDN으로 제공한다.
- **편집 도구:** 콘텐츠 파일이 수만 개가 되면 DB 기반 편집 도구로 옮길지 판단한다. 지금의 JSON 원본과 빌드 검증 원칙을 잃지 않는 방식이어야 한다.
- **언어판 빌드:** 다국어 빌드, 언어별 사이트맵, `hreflang` 검증을 자동 검사에 넣는다.

### P3-W8. 위험 관리

- **생성형 AI 검색:** 검색 클릭이 줄 수 있다. 검색 외 유입(참여, 커뮤니티, 뉴스레터, 직접 방문, 영상)을 전체의 35% 이상으로 유지한다.
- **검색 알고리즘 변경:** 한 유형이나 한 언어가 전체 유입의 50%를 넘지 않게 분산한다.
- **권리:** 분기마다 이미지, 영상, 가사 이용 근거를 감사한다. 근거가 없는 자료는 내린다.
- **운영 부담:** 자동화 처리량은 사람 검수 능력에 맞춘다. 표본 오류율 2% 기준은 계속 적용한다.

## 점검과 방향 전환 기준

- **2028년 6월 말:** 월 25만 미만이면 목표 시점을 다시 잡는다. 상위 2~3개 유형과 상위 언어판에만 집중한다.
- **분기마다:** 유형·언어판별 페이지당 방문과 생산 비용을 비교해 투입을 다시 나눈다.
- **수익:** 재원(F5)이 운영 비용의 50%를 2분기 연속 넘지 못하면 인력 확장을 멈추고 자동화 비중과 범위를 조정한다.
